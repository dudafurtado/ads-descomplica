Programação Estruturada é um jeito de programar organizando o código em blocos lógicos, 
com começo, meio e fim, para deixar o programa mais claro, fácil de entender e fácil de 
manter.

Ela se baseia principalmente em três estruturas:

1. Sequência

As instruções são executadas uma depois da outra.

nome = "Maria"
idade = 20
print(nome)
print(idade)
2. Decisão

O programa escolhe um caminho conforme uma condição.

idade = 18

if idade >= 18:
    print("Maior de idade")
else:
    print("Menor de idade")
3. Repetição

O programa repete uma ação várias vezes.

for numero in range(1, 6):
    print(numero)

Na prática, programação estruturada evita código bagunçado e cheio de saltos aleatórios. Ela 
usa funções, condições e laços para organizar a lógica.

Exemplo simples:

def verificar_idade(idade):
    if idade >= 18:
        return "Maior de idade"
    else:
        return "Menor de idade"

resultado = verificar_idade(20)
print(resultado)

Resumindo: programação estruturada é programar de forma organizada, usando sequência, decisão 
e repetição para resolver problemas.
